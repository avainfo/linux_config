Workstation Configuration Summary

Bootstrap
- Single entrypoint: ./install.sh
- Modes: --full, --user-only, --system-only, --root-dotfiles
- Optional: --docker, --no-system, --dry-run
- Do not run install.sh itself with sudo; privileged steps call sudo internally.

42 workstations
- Detected from the mounted /goinfre filesystem and writable ~/goinfre, never from a username.
- Neovim cache/state/data are redirected to ~/goinfre/nvim.
- ~/.config/nvim remains the portable tracked configuration.
- Project-specific uv/Hugging Face environments are intentionally not exported globally.

Terminal / shell
- Kitty config: ~/.config/kitty/kitty.conf
- Zsh config: ~/.zshrc
- Powerlevel10k config: ~/.p10k.zsh
- Oh My Zsh, Powerlevel10k and shell plugins are installed/updated by the main bootstrap.

Editors
- Vim config: ~/.vimrc
- Neovim config: ~/.config/nvim
- Neovim plugins are managed with lazy.nvim.
- clangd config: ~/.config/clangd/config.yaml

Tmux
- Config: ~/.tmux.conf
- Truecolor, mouse support, vi copy mode, fast splits and custom status/pane formatting.

Git
- Config: ~/.gitconfig
- User identity, aliases, push defaults and colors are tracked.

Debugging / reliability
- GDB config: ~/.gdbinit
- Main bootstrap can install GDB, LLDB, Valgrind, strace, ltrace, coredump tooling, stress tools and tracing/network diagnostics.
- Linux system tuning is applied with drop-ins under /etc/systemd/*conf.d and /etc/sysctl.d.

Scripts
- Repository scripts and dotfiles/bin helpers are linked into ~/bin.
- Nested directories such as ~/bin/jetbrains are preserved.

Backups
- Conflicting user configuration can be backed up under ~/.config/ava/backups/<timestamp>/ before replacement.
- Root dotfiles are copied, not symlinked to a user-owned checkout.
